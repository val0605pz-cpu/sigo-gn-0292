# Práctica 03: Módulo de Expedientes

## Objetivo
Desarrollar un módulo de expedientes que permita administrar información mediante un sistema de archivos JSON.

## Tecnologías utilizadas
- React para la interfaz gráfica.
- Node.js y Express para el servidor.
- JSON para almacenar los expedientes.

## Funciones del sistema
- Registrar expedientes.
- Consultar expedientes.
- Editar información.
- Eliminar expedientes.
- Guardar cada expediente en un archivo JSON independiente.

## Resultado
Se desarrolló un módulo funcional que permite administrar expedientes desde una interfaz web conectada a un servidor Express.
